⛪ 장호원성결교회 반응형 홈페이지 구축 & GitHub 올리기 가이드 초보자분도 프로그램 설치 필요 없이, 웹사이트 클릭만으로 5분 만에 무료 홈페이지를 개설하실 수 있습니다. 차근차근 따라서 진행해 보세요! 1단계: GitHub 계정 만들기 GitHub 공식 홈페이지(github.com)에 접속합니다. 오른쪽 상단의 Sign up (회원가입) 버튼을 클릭합니다. 사용하실 이메일 주소, 비밀번호, 사용자 이름(Username)을 입력하고 가입을 완료합니다. 이메일로 발급된 인증번호 6자리를 입력하여 계정 인증을 마칩니다. 2단계: 새 저장소(Repository) 만들기 로그인 후 화면 오른쪽 상단의 + 아이콘을 클릭하고 New repository를 선택합니다. 각 항목을 다음과 같이 설정합니다: Repository name: janghowon-church (영문 소문자로 적어주세요) Description (선택): 장호원성결교회 반응형 홈페이지 Public / Private: 반드시 Public(공개)을 선택해야 무료로 웹사이트 주소가 만들어집니다. 아래 항목들(Add a README file 등)은 모두 체크 해제 상태로 둡니다. 하단의 초록색 Create repository 버튼을 클릭합니다. 3단계: 홈페이지 파일(index.html) 업로드하기 새로 생성된 저장소 화면 중앙에 있는 uploading an existing file 링크를 클릭합니다. 내 컴퓨터에 저장된 index.html 파일(그리고 이미지 등의 폴더)을 마우스로 드래그하여 파일 업로드 영역에 넣습니다. 화면 하단의 Commit changes 초록색 버튼을 클릭하면 파일이 저장소에 업로드됩니다. 4단계: 무료 인터넷 주소(GitHub Pages) 연결하기 저장소 상단 메뉴 탭 중에서 Settings (톱니바퀴 아이콘)를 클릭합니다. 좌측 사이드바 메뉴 중 Pages 항목을 클릭합니다. Build and deployment 구역의 Branch 설정을 확인합니다: None으로 되어 있는 드롭다운 메뉴를 클릭하여 main (또는 master)으로 변경합니다. 오른쪽의 Save 버튼을 클릭합니다. 약 1~3분 후, 페이지를 새로고침(F5)하면 상단에 다음과 같이 민트색 배경의 메시지와 함께 인터넷 주소가 생성됩니다: "Your site is live at https://사용자이름.github.io/janghowon-church/" 이제 해당 주소를 누르면 전 세계 어디서나 접속 가능한 장호원성결교회 홈페이지가 열립니다! 5단계: 추후 내용 수정 및 업데이트 방법 홈페이지의 문구나 사진을 수정하고 싶을 때는 두 가지 방법이 있습니다. 방법 A: 깃허브 웹상에서 직접 수정하기 (간단한 글자 수정시) 깃허브 저장소에서 index.html 파일명을 클릭합니다. 오른쪽 상단의 연필 모양 아이콘 (Edit this file)을 클릭합니다. 수정할 글자(예: 예배 시간, 공지사항 등)를 고친 후, 우측 상단의 Commit changes... ➔ Commit changes를 클릭합니다. 방법 B: 파일 전체 다시 올리기 저장소 메인 화면에서 Add file 버튼 ➔ Upload files를 선택합니다. 새로 수정한 index.html 파일을 다시 드래그하여 올린 후 Commit changes를 누르면 자동으로 덮어씌워집니다. 6단계: 서브페이지 추가 및 공통 메뉴(JS) 확장 구조 여러 서브 페이지(교회소개, 오시는길 등)를 늘려갈 때는 다음과 같은 폴더 구조로 관리하시면 효율적입니다: janghowon-church/ ├── index.html (메인 페이지) ├── greeting.html (인사말 페이지) ├── map.html (오시는길 페이지) ├── assets/ │ ├── js/ │ │ └── common.js (공통 헤더/푸터 스크립트) │ └── images/ (교회 사진, 담임목사님 사진 등) 새 페이지를 만드실 때 index.html을 복사한 후 파일 이름만 변경하고, 본문 카드 영역의 내용만 수정하시면 간단히 새 서브페이지를 완성할 수 있습니다.
